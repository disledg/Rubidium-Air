# Rubidium Air - Система управления воздушными судами

## Описание
Система управления воздушными судами и их метриками, разработанная на C# с использованием WPF и Entity Framework.

## Требования
- .NET Framework 4.8
- SQL Server (LocalDB или полная версия)
- Visual Studio 2019 или новее

## Установка и настройка

### 1. Клонирование репозитория
```bash
git clone https://github.com/disledg/Rubidium-Air.git
cd Rubidium-Air
git checkout Aircraft-module
```

### 2. Настройка базы данных
1. Откройте SQL Server Management Studio
2. Подключитесь к вашему SQL Server
3. Откройте файл `Database/CreateDatabase.sql`
4. Выполните скрипт для создания базы данных и таблиц

### 3. Настройка строки подключения
1. Откройте файл `App.config`
2. Найдите строку подключения `AirportDBEntities1`
3. При необходимости измените `data source=(localdb)\MSSQLLocalDB` на имя вашего сервера

### 4. Установка пакетов NuGet
В Package Manager Console выполните:
```powershell
Update-Package -reinstall
```

### 5. Сборка и запуск
1. Откройте решение `Rubidium.sln` в Visual Studio
2. Нажмите F5 для сборки и запуска проекта

## Основные функции

### Модуль Aircraft (Воздушные суда)
- Управление данными о воздушных судах
- Добавление, редактирование и удаление ВС
- Просмотр списка всех ВС

### Модуль AircraftMetrics (Метрики ВС)
- Мониторинг показателей воздушных судов
- Графики расхода топлива
- Отслеживание загрузки и технического состояния
- Фильтрация по датам

## Структура проекта
- `Database/` - Скрипты базы данных
- `ORM/` - Модели, репозитории и сервисы
- `UI/` - Представления и ViewModels
- `TestsForRubidiumAir/` - Модульные тесты

## Разработка
Проект следует архитектуре MVVM и использует:
- Entity Framework для работы с базой данных
- LiveCharts для визуализации данных
- Современный UI в темной теме
